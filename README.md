# VibeLab project pages

Published project websites:

- [ELP](https://vibe-hust.github.io/elp/)
- [AutoCache](https://vibe-hust.github.io/autocache/)
- [ARLIFT](https://vibe-hust.github.io/arlift/)

Each project has its own folder, page, scripts, and media. Edit the corresponding
folder to update a website. Shared author and repository-link styling lives in
`project-meta.css`.

GitHub Pages publishes the root of `main` automatically. This is a static site:
no installation or build step is required. The `.nojekyll` file disables Jekyll.

Code repositories:

- https://github.com/vibe-hust/elp_code
- https://github.com/vibe-hust/autocache_code
- https://github.com/vibe-hust/arlift_code
